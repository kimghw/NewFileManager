# 연차보고서 취합 — `report_merge` (준비 중)

> 이 파일은 워크플로우 등록부 `app/workflow.py` 에서 **만든 글**이다(TASK 문서 — 화면 `/workflow` 의 이 TASK 절과 같은 내용) — 손으로 고치지 않는다.
> 등록부를 고치면 `python -X utf8 tools/workflow_md.py` 로 다시 만든다(안 맞으면 `tests/test_workflow.py` 가 떨어진다). 사양 [spec/spec_워크플로우.md](../spec/spec_워크플로우.md) ② §10.
>
> [workflow.md](../workflow.md) 가 모든 TASK 의 차례를 보이는 **전체 지도**라면 이 글은 이 TASK 하나의 **세부**다 — 시작할 때 저절로 확인하는 것(시작 점검)과 단계마다 조건을 함께 적는다.

기관이 나눠 쓴 문서의 내용을 연차보고서 하나로 모읍니다.

- 받는 문서: 연차보고서(취합본) + 기관 문서들
- 산출물: 기관의 내용을 모은 연차보고서 하나
- 알아 둘 것: 준비 중입니다 — 카드만 있고 실행 모듈이 없습니다.
