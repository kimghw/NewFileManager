# 수식 — 캡처를 LaTeX 로

<!-- 문서 라이브러리 서버의 스킬 글(기본본) — 따로 캡처한 수식 그림을 LaTeX 로 바꾸는 호출의 판단 기준. 답의 꼴은 doclib/extract.py FORMULA_CONTRACT. -->

- 그림에 **보이는 대로** 옮긴다 — 식을 정리하거나 고쳐 쓰지 않는다(틀려 보여도 그대로). 기호 · 첨자 · 분수 · 근호 · 합 · 적분 · 행렬 · 괄호의 크기를 그대로.
- 수식 본문만 적는다(`$$` · `\[` 로 두르지 않는다). 수식 번호 「(3)」 이 보이면 `\tag{3}` 으로 붙인다.
- 여러 줄 수식은 `\begin{aligned} … \end{aligned}` 로, 경우 나눔은 `\begin{cases} … \end{cases}` 로.
- 한글 · 낱말이 섞였으면 `\text{…}` 로 싼다. 단위는 `\mathrm{…}`.
- 표준 LaTeX(amsmath)만 쓴다 — 정의되지 않은 매크로를 만들지 않는다.
- 그림이 수식이 아니거나(글 문단 · 그림 조각) 일부가 잘려 읽을 수 없으면 ok 를 거짓으로 하고 note 에 까닭을 적는다. 읽을 수 없는 글자를 짐작해 채우지 않는다.
