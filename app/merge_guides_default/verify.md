## 무엇을 가리나

- 검증은 **웹이 문서를 제대로 읽었는가**(가져오기) · **저장본이 고친 곳만 바뀌었는가**(출력파일)를 본다. 한글·Word 가 찍은 PDF 는 그것을 재는 **기준**일 뿐 정답이 아니다.
- 다름이 **문서의 서식·글을 따라** 생겼으면 실제 문제(`real`)다 — 특정 문단·런·표에서만, 웹이 읽은 값과 문서 XML 의 값이 다르다고 볼 근거가 있을 때.
- 다름이 **PDF 를 찍는 쪽의 사정**으로 생겼으면 기준 쪽 사정(`reference`)이다 — 문서의 서식과 무관하게 한 PDF 글꼴·한 종류의 글자·한 프로그램 동작에 몰려 있을 때.
- 둘이 섞였으면(`mixed`) 실제 문제 쪽을 까닭에 먼저 쓴다. 자료로 가릴 수 없으면 짐작하지 말고 `unclear`.

## 가리는 법

- **몰림을 본다**: 다른 글자가 PDF 글꼴 하나에 거의 다 몰려 있고(그 글꼴의 글자 수 ≈ 다른 글자 수), 방향이 한쪽뿐이면(모두 「웹 보통 · PDF 굵게」) 기준 쪽 사정이다.
  글꼴 판정 줄의 `bold`(굵게 짝 — 「보통→굵게」 글자 수)가 그 근거다. 같은 PDF 글꼴 안에서 웹 굵게·보통이 섞여 있는데 PDF 는 한 가지뿐이면 PDF 가 굵게를 가리지 못하는 것이다.
- **방향과 범위를 본다**: 문서 전체에 고르게 퍼진 다름은 출력 쪽 동작일 때가 많고, 특정 문단 몇 개에만 있는 다름은 웹 읽기·저장의 문제일 때가 많다.
- **판정하지 못한 것**(`unjudged`)은 통과로 셈하지 않는다 — 그것 때문에 판단이 안 서면 `unclear` 로 두고 까닭에 무엇을 몰라서인지 쓴다.
- 패키지 왕복 · XML 재직렬화 · 웹 매핑의 다름은 PDF 와 무관하다 — 기준 쪽 사정으로 볼 근거가 자료에 없으면 실제 문제다.

## 알려진 기준 쪽 사정 (한글 PDF — 이 PC)

- **함초롬바탕 → 굵은 파일**: 한글이 함초롬바탕 보통 글자를 굵은 글꼴 파일(`HCRBatang-Bold`, 굵게 비트 켜짐)로 찍는다 — 문서 글자 모양에 굵게가 없어도. 이 PC 의 한글 PDF 에는 보통 `HCRBatang` 이 나오지 않는다.
  그래서 함초롬바탕 글자의 「굵게 다름(웹 보통 · PDF 굵게)」 은 기준 쪽 사정이다. 같은 글꼴의 진짜 굵게 오류도 이 PDF 로는 가릴 수 없다(까닭에 그렇게 적는다).
- **돋움체 · 바탕 → HCR Batang Bold**: 이 글꼴이 PC 에 없을 때 한글이 보통·굵게 모두 `HCRBatang-Bold` 로 찍은 적이 있다. 자동 글머리 「◦」 도 글이 굵지 않아도 `HCRBatang-Bold` 로 찍혔다.
- **Type3 글꼴(한글 전용 글꼴 HFT — 한양중고딕 · 한양견고딕 …)**: 이름 없는 Type3(`T1`·`T8` …)로 찍혀 굵게·글꼴 이름을 PDF 로 알 수 없다 — 스크립트가 이미 「모름」 으로 뺀다.
- **가짜 굵게**: 돋움이 설치돼 있으면 굵은 글자를 같은 글꼴에 획을 덧그려 찍는다(굵게 비트 없음) — 스크립트가 긋기까지 본다. 돋움이 없으면 `HCR Dotum Bold` 파일로 바뀐다.
- **글꼴 대체**: 문서 글꼴이 PC 에 없으면 한글이 다른 글꼴로 찍는다(한컴돋움 → HCRDotum · 「Arial」 → 맑은 고딕 · 한양중고딕 영문 → 돋움). 「둘 다 대체」 는 같은 대체이므로 문제가 아니다.
  이름이 한글인 글꼴(휴먼명조)은 PyMuPDF 가 「????」 로 읽는다.
- **렌더 비교의 미세 차이**: 글·기호·줄 자리·그림이 같고 글자 가장자리 픽셀만 다른 쪽은 한글이 그 구역을 다시 조판하며 생긴다 — 눈으로 확인할 거리이지 실패 근거가 아니다.
- **쪽 나눔**: 한글 PDF 는 한 쪽의 본문 글을 먼저, 표 칸 글을 뒤에 쓰는 일이 많다. 맨 위 줄이 짧거나 빈 쪽은 확인하지 못한 것이다(실패 아님).

## 알려진 기준 쪽 사정 (Word PDF)

- Word 는 줄 끝마다 빈칸을 찍는다(스크립트가 뗀다). Symbol · Wingdings 글머리는 PDF 에도 사용자 영역 글자(U+F0xx)로 남는다(스크립트가 웹 라벨과 같은 글자로 바꾼다).
- Word 는 본문 · 칸이 표로 끝나면 다시 저장할 때 빈 문단을 하나 더한다(셈에서 뺀다).
- Word PDF 의 글꼴은 TrueType 이름이 남아(`MalgunGothic`·`MalgunGothicBold`) 이름으로 맞출 수 있다.
