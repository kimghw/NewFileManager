# 템플릿(사슬·가지) · 인스턴스 · 조정 지침

## 템플릿 = 레터 사슬 하나
- 템플릿은 레벨마다 레터 계열 하나인 **한 줄 사슬**이다. 예: 주 사슬 「1. › 1-1. › (1) › o › - › ⋅」 6레벨. **번호형에서 기호형으로 바뀌는 곳은 끊는 곳이 아니다.**
- **가지 자리**: 한 부모 아래 레터 계열이 둘 이상 오면(1-1. 아래 (N)·o·□·라벨) 가장 많이 쓰인 레터가 부모 사슬을 잇고, 나머지 레터는 그 노드부터 **다른 템플릿**(가지 템플릿,
  뿌리 = L1)이 된다 — 이것이 이종 형제.
- **구분 라벨·괄호 소제목은 그 줄부터 새 템플릿**(그 줄 = L1, 아래 내용 = L2…) — 구분 라벨 「[기관] › o › -」, 괄호 소제목 「[…] › o › -」.
  구분 라벨 = 구분 기준(단계·차년도·기관 …) 값이 든 괄호 줄, 괄호 소제목 = 그 밖의 괄호 글.
- 템플릿의 정체 = **사슬 꼴**(scope:레터 열 — 앵커). 같은 꼴이면 어디에 매달려도 **같은 템플릿 하나**(정의 1개 + 인스턴스 여럿, id #1 = 주 사슬, 가지는 문서 순 첫 등장).
  2. 안의 가지와 6. 안의 가지가 같은 #k 일 수 있다. 같은 레터가 여러 템플릿에 들 수 있다(「o」 = 주 사슬 L4 · 「o › - › ⋅」 L1 · 「[기관] › o › -」 L2).
- 뿌리 글자가 같고 이어짐이 다른 꼴(「□ › o」·「□ › ①」)은 공통 「□ › o」 + □ 아래 「①」 가지로 합성해 둔다(공통 틀 해석 — 두 꼴이 같았다는 뜻은 아님).
- **주제가 비슷하다는 이유만으로 템플릿을 합치지 않는다.** 되풀이가 한 번뿐이어도 가지 템플릿이다(인스턴스 1개).

## 인스턴스
- 템플릿 L1 이 나타나는 모든 자리(가지 뿌리·라벨·주 사슬의 1.·2.·… 각각)가 인스턴스 하나 — 뿌리 노드·매달린 부모·구분 값(라벨 글·「(1) 1차년도」 의 차년도)을 가진다.
- 레벨 하나가 빠진 것(빈 양식)·안내가 더 붙은 것은 같은 템플릿의 **편차**(missing).

## 조정(같은 템플릿 슬롯으로 보기)
- 같은 템플릿·같은 레벨(슬롯)인데 서식 라벨이 다르면: 오차 기준(tolerance) 안이면 대표 서식으로 조정, 밖이면 **같은 구실**(같은 단계의 보통 항목)인지 판단 —
  같은 구실이면 조정(까닭), 일부러 다른 것(소제목·안내·인용·상자 글·자리표시·강조)이면 다름 유지. 구분 라벨·괄호 소제목 템플릿의 L1(그 줄 자신)도 슬롯이다.
- 판정은 **슬롯마다** 따로다 — 같은 서식 쌍이 다른 슬롯(다른 템플릿·레벨)에 나오면 그 슬롯의 구실로 다시 판단한다. 확신이 없으면 다름 유지.

## 재검토(조정 판정을 다시 보기)
- 조정 판정은 두 번 한다: 1차(위 기준으로 쌍마다 판정) → **재검토**(1차 맥락이 없는 새 호출이 1차 판정과 까닭을 받아 반박 검증).
- 재검토는 1차 까닭을 그대로 믿지 않고 서식 이름(글꼴·크기·굵게·정렬·여백·간격)과 예문으로 **스스로 먼저 판정**한 뒤 1차와 견준다.
  같은 결론이면 동의(agree), 다르면 불일치(disagree — 1차가 틀린 까닭을 적음). 확신이 없으면 「다름」(same false) 으로 답한다 — 1차가 조정이면 불일치가 되어 미판정,
  1차가 다름 유지면 동의.
- 불일치한 쌍은 조정하지 않고 **미판정**으로 남겨 사람이 정한다(1차·재검토 까닭을 함께 보인다). 재검토가 실패한 쌍은 1차 판정 그대로(「재검토 못 함」 표시).
