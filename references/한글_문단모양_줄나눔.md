# 한/글 문단 모양·정렬·줄 나눔 규칙 (2026-10-28)

한/글 [서식-문단 모양](Alt+T) [기본] 탭의 항목이 화면에서 무슨 뜻인지, HWP5 명세 비트와 HWPX 요소가 어디에 대응하는지 정리했다.
줄 배치 캐시(lineseg)·textpos·vertpos·줄간격 계산은 [HWPX_포맷.md](HWPX_포맷.md) § 조판 규칙이 원본이다.

## 정렬 방식 (HWP5 속성1 bit 2–4, HWPX `hh:align horizontal`)

| 값 | 한/글 | 동작 |
|---|---|---|
| 0 `JUSTIFY` | 양쪽 정렬 | 양쪽 끝을 맞춤(가장 흔함) |
| 1 `LEFT` | 왼쪽 | 왼쪽 끝을 맞춤 |
| 2 `RIGHT` | 오른쪽 | 오른쪽 끝을 맞춤 |
| 3 `CENTER` | 가운데 | 가운데로 모음 |
| 4 `DISTRIBUTE` | 배분 | 글자 수와 무관하게 양쪽을 맞추고 **글자 사이**를 고르게 띄움 |
| 5 `DISTRIBUTE_SPACE` | 나눔 | 글자 수와 무관하게 양쪽을 맞추고 **어절 사이**를 고르게 띄움 (= 한/글 97 의 배분 정렬) |

- 도움말: 왼쪽·오른쪽·가운데 정렬을 **고르면** 한글 줄 나눔 기준이 자동으로 '어절'로 바뀐다 — 대화상자 동작이다.
  파일에는 가운데 + 글자 조합도 있다 ✔(가운데+KEEP_WORD 문단 다수, 낱말 중간 나눔 51건).
- 단축키: 양쪽 Ctrl+Shift+M, 왼쪽 L, 오른쪽 R, 가운데 C, 배분 T(나눔은 없음).
- HWPX `hh:align vertical`(BASELINE·CENTER·TOP…) = 줄 안 세로 정렬(HWP5 bit 20–21: 글꼴 기준·위·가운데·아래).

## 줄 나눔 기준

낱말 일부가 오른쪽 여백에 걸려 낱말 전체가 다음 줄로 넘어가면 앞줄의 낱말 사이가 지나치게 벌어진다. 이를 줄 끝 나눔 단위와
최소 공백으로 조정한다.
- **한글 단위**(줄 끝에 한글이 올 때): [글자] = 음절 사이 어디서나 / [어절] = 띄어쓰기에서만. 한/글 기본은 글자.
  HWP5 bit 7(0 어절, 1 글자). HWPX `hh:breakSetting breakNonLatinWord` — **KEEP_WORD = 글자, BREAK_WORD = 어절** ✔
  (이름과 반대, 근거는 HWPX_포맷.md).
- **영어 단위**(줄 끝에 영어가 올 때): [단어]·[하이픈]·[글자]. HWP5 bit 5–6(0 단어, 1 하이픈, 2 글자). HWPX `breakLatinWord`.
- **최소 공백** 0~75%(HWP5 bit 9–15): 낱말 사이 빈칸을 이 비율까지 줄여 줄 끝 낱말을 그 줄에 남긴다 — 양쪽 정렬 줄이
  화면 글꼴로 측정한 것보다 촘촘히 들어갈 수 있는 이유다.
- 도움말 권장: 한글·영문이 섞인 문장은 한글 = 글자, 영문 = 단어.
- 강제 줄 바꿈 Shift+Enter(문단은 그대로) = HWPX `hp:lineBreak`(HWP5 문자 10, char 컨트롤 1칸).
- HWP5 표 45: bit 0–1 한 줄로 입력, bit 4 한글-영어 간격 자동 조절, bit 5 한글-숫자 간격 자동 조절
  (HWPX `hh:breakSetting lineWrap`, `hh:autoSpacing eAsianEng eAsianNum`).

## 여백·첫 줄·간격

- **여백**: 편집 용지의 왼쪽/오른쪽 여백에 더해 이 문단에만 주는 왼쪽·오른쪽 여백.
- **첫 줄**: 보통 / 들여쓰기(첫 줄이 문단 왼쪽 여백보다 안쪽에서 시작) / **내어쓰기(첫 줄은 그대로, 나머지 줄이 그 값만큼 안쪽)**.
  HWPX `hc:intent` 음수 = 내어쓰기 — CSS `text-indent` 음수와 뜻이 반대(HWPX_포맷.md § 서식 정의).
  빠른 내어쓰기 Shift+Tab(커서 위치 기준, 표 안은 Ctrl+Shift+Tab), 첫 줄 한 글자 내어/들여 Ctrl+F5/Ctrl+F6.
- **단위**: 기본 pt(1pt ≈ 0.35146mm), mm·cm·pi·px·ch(글자 — 바탕글 영문 글자 크기 기준)·gp(급)·인치.
- **간격**: 줄 간격(글자에 따라 % / 고정 값 / 여백만 지정 / 최소 — HWP5 표 46), 문단 위·아래. **편집 용지의 줄 격자 사용**
  (HWP5 bit 8, HWPX paraPr `snapToGrid`)은 체크한 문단에만 용지 줄 격자를 적용.
- 그 밖의 HWP5 속성1 비트: 16 외톨이줄 보호, 17 다음 문단과 함께, 18 문단 보호, 19 문단 앞에서 항상 쪽 나눔,
  22 글꼴에 어울리는 줄 높이, 23–24 문단 머리(없음·개요·번호·글머리표), 25–27 수준(1~7), 28 테두리 연결, 29 여백 무시.
  HWPX: `widowOrphan`·`keepWithNext`·`keepLines`·`pageBreakBefore`(breakSetting), `fontLineHeight`(paraPr), `hh:heading`.

## 브라우저로 옮길 때

- 글이 그대로인 문단은 저장된 줄 나눔(lineseg textpos)을 그대로 강제하는 것이 가장 정확하다 — 글꼴이 달라도 줄 수가 같다.
- 고친 문단을 다시 흐르게 할 때: 한글 단위 어절(BREAK_WORD) ≈ CSS `word-break: keep-all`, 글자(KEEP_WORD) ≈ 기본(`normal`,
  한글 음절 사이 나눔). 최소 공백·장평·자간은 CSS 로 정확히 재현할 수 없다(근사).
