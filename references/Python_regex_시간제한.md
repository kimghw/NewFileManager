# Python `regex` 패키지 — LLM 이 만든 정규식을 시간 제한으로 돌리기

사용처: `app/heading_rules.py`(헤딩 추출 배운 규칙, spec_헤딩_추출 ② §2). 판: `regex==2026.9.29`.

- 표준 `re` 에는 시간 제한이 없다. `regex` 는 `pattern.match(s, timeout=초)` 를 받아 넘으면 `TimeoutError` — 규칙 하나를 건너뛰고 경고로 남기는 데 쓴다.
- `regex` 는 고전적인 파국 꼴 일부를 스스로 빨리 끝낸다: `(a+)+$` 를 `'a'*30 + 'b'` 에 대면 ~0 ms 에 「안 맞음」(2026-11-09 실측) — 시간 제한 시험에 쓰면 안 걸린다.
  `(a|aa)+$` 는 여전히 지수적이라 제한에 걸린다(시험용).
- 역참조(`\1`)·조회 길이 같은 막이는 패턴 글을 보고 따로 한다(`regex` 에도 정적 검사는 없음).
